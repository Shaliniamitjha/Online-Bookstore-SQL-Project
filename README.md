# 📚 Online Bookstore SQL Project

## 🚀 Project Overview
This project is a **relational database system** for an Online Bookstore built using **MySQL**.  
It demonstrates how real-world data is structured, managed, and analyzed using SQL queries.

The project includes database creation, table relationships, sample datasets, and both basic and advanced SQL queries to solve real business problems.

---

## 🗂️ Project Files
- 📘 **Books.csv** → Contains book details like title, author, genre, price, and stock
- 👤 **Customers.csv** → Contains customer information like name, city, and country
- 🛒 **Orders.csv** → Contains order details like book ID, customer ID, quantity, and total amount
- 🧾 **Online Book_Store.sql** → Contains database schema, table creation, and SQL queries
  
---

## 🧠 SQL Concepts Used
- Database & Table Creation
- Primary Key & Foreign Key Relationships
- INSERT INTO statements
- SELECT Queries
- WHERE Filtering
- ORDER BY Sorting
- GROUP BY & HAVING
- INNER JOIN & LEFT JOIN
- Aggregate Functions (COUNT, SUM, AVG)
- COALESCE Function

---

## 📊 Basic Queries Covered
- Retrieve books by genre
- Filter books based on publication year
- List customers by country
- Analyze orders by date
- Calculate total stock
- Identify expensive books
- Customer order analysis

---

## 🔥 Advanced Queries Covered
- Total books sold per genre
- Average price of books in a genre
- Customers with multiple orders
- Most frequently ordered books
- Top 3 expensive books in a genre
- Total quantity sold by author
- High spending customers analysis
- Remaining stock after orders
